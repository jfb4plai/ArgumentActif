ArgumentActif
Avant le débat — réglages

Tu animes un débat en classe ; tu notes ce qui est dit ; l'outil affiche sur le tableau le type de mouvement argumentatif (sophisme, appel à l'émotion, généralisation…) — jamais un jugement. Ce sont les élèves qui construisent la réponse. Bilan à la fin dans l'onglet Débriefer.

Ce sujet s'affiche sur la projection vue par la classe.

Si l'école a déployé le proxy PLAI. Aucune clé ne transite par le navigateur.

Comment ça marche
  1. Clique « Projection ↗ » (en haut) : une fenêtre s'ouvre. Envoie-la sur le vidéoprojecteur — Windows : touche ⊞+P puis « Dupliquer » ; Mac : Recopie vidéo. Garde cette fenêtre ouverte pendant tout le débat.
  2. Quand un·e élève parle : note son propos ci-dessous, puis « Classer ».
  3. L'étiquette apparaît sur la projection. Recommence à chaque prise de parole.
  4. Débat terminé → onglet « Débriefer » pour l'analyse avec la classe.
